Backup and restore

All financial information is stored in this browser on this device. Back up regularly, especially before changing phones or clearing browser data.

Restoring replaces all existing data. Keep your backup private because it contains financial details.

Install and privacy

On Android Chrome: open the hosted app, tap the browser menu and choose Install app or Add to Home screen. On desktop Chrome or Edge, use the install icon in the address bar if available.

Offline access requires opening the hosted app once while connected to the internet. Your entries remain on this device; no account or cloud sync is included.
