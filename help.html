Frequently asked questions

How do I receive my app?

After buying through Payhip, follow the download and installation instructions provided with your purchase. Your activation code is sent separately by email.

How many devices can I use?

One paid-app licence can be activated on up to two devices. A third device cannot be activated with the same licence.

Where is my activation code?

Check the email inbox and spam/junk folder for the address used at checkout. If it has not arrived, contact support with your order details. Never include your licence code in a public message.

Can I use my app without an internet connection?

Many Elevor360D apps are designed for offline use after setup. Some features, updates or initial licence activation may require internet access. Check the individual app description.

How do I install on Android?

Open the app link in Chrome. Use the Install app option if shown, or open the browser menu and choose Add to Home screen or Install app. The wording depends on your device and browser.

How do I install on Windows?

Open the app link in Chrome or Edge. Use the install icon in the address bar or the browser menu if installation is supported.

How do I back up my saved data?

If your app includes Backup/Export, use it regularly and save the downloaded backup file somewhere safe. To restore, use the app’s Restore/Import function and select the appropriate backup file.

Will uninstalling delete my information?

Locally stored app data may be lost if you uninstall the app, clear browser storage or change devices. Make a backup first whenever the app supports it.

What if the app does not open or install?

Check your internet connection for the initial setup, reload the app, and try Chrome or Edge. If it still fails, use the contact form and include your device, browser, app name and a description of the problem.

What if my licence will not activate?

Double-check the code, make sure you are online during activation, and confirm the two-device limit has not already been reached. Contact support if the issue continues.

Troubleshooting checklist

  1. Confirm you are using the correct app link and licence code.
  2. Connect to the internet for initial installation or activation.
  3. Try reloading the page or reopening the app.
  4. Check whether your browser offers the Install app option.
  5. For saved-data problems, use your app's backup and restore tools if available.
  6. If the issue persists, contact support with the exact error message.

Backup & restore

Where an app provides Backup or Export, save a copy regularly outside the app, such as in a safe folder or cloud storage. To restore, open the app's Restore or Import option and select the matching backup file. Always check that your backup is complete before deleting data or changing devices.
